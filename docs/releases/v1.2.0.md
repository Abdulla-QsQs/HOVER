# HOVER 1.2.0

HOVER 1.2.0 completes background reminder delivery for the Windows app and installable mobile companion.

## Highlights

- Install HOVER Mobile directly from Settings with dedicated 192 px and 512 px Home Screen icons.
- Register device-specific Web Push subscriptions after secure pairing.
- Schedule reminders with IANA timezones and encrypted RFC 8291 delivery for iPhone and Android.
- Retry temporary push-service errors, deduplicate reminder occurrences, and disable expired endpoints.
- Send a test notification from HOVER Mobile Settings.
- Run a protected minute-level cloud dispatcher without requiring the Windows laptop to stay on.
- Keep Windows alarms alive in the system tray and launch HOVER automatically at sign-in.
- Prevent API and signed pairing responses from entering the offline cache.

## Verification

- Mobile runtime-integrity and TypeScript production builds.
- D1 pairing, recovery, sync, subscription, authentication, dispatch, deduplication, unsubscription, and packaging integration tests.
- Standards-compliant `aes128gcm` push payload verification.
- Scheduler syntax and protected-dispatch checks.
- Windows JavaScript checks, Electron snapshots, NSIS packaging, and SHA-256 release checksum.
