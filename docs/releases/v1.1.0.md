# HOVER 1.1.0

HOVER 1.1.0 adds the secure mobile-companion foundation and finishes the GitHub-style completion-history redesign.

## Highlights

- First-launch iPhone/Android choice inside the Windows app.
- Real, expiring QR pairing sessions with a six-character manual fallback.
- Separate phone and desktop device tokens plus recovery-code restore.
- Cloud-backed usernames, reminders, deletion state, and completed history.
- GitHub-style mobile completion map with month and weekday labels, clearer inactive cells, exact `#541804` activity fill, and smooth staggered motion.
- New clean screenshots for the calendar, island, first-launch pairing, and QR state.
- Background sync uses bounded network timeouts so offline service cannot freeze the HOVER window.

## Verification

- Windows JavaScript syntax checks.
- Mobile runtime-integrity check and production build.
- D1-backed pairing, recovery, username, reminder, deletion, and completion integration tests.
- Electron visual snapshots and Chrome interaction review.
- Windows NSIS installer build and SHA-256 checksum.
