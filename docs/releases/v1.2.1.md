# HOVER 1.2.1

HOVER 1.2.1 turns the mobile companion into a clean standalone Home Screen experience and removes the personal ChatGPT Sites address from every public install path.

## Highlights

- Install from the neutral free address `https://hover-reminder.pages.dev/`.
- Launch edge-to-edge on iPhone, iPad, and Android without the desktop preview's fake phone, device menu, or circular cursor.
- Use the phone's real status bar, safe areas, native keyboard, momentum scrolling, and touch behavior.
- Keep the approved OLED-black glass planner, onboarding, reminder sheet, completion flow, and GitHub-style activity history.
- Resolve `TODAY`, the calendar heading, current-time line, and seed reminders from the phone's local clock.
- Use black-backed Apple and maskable icons so transparent edges no longer become a white iOS tile.
- Route desktop QR pairing through the neutral HOVER address while preserving existing cloud profiles, tokens, recovery codes, alarms, and scheduled push delivery.
