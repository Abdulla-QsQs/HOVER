# HOVER 1.0.1

This security update replaces HOVER 1.0.0 and is the recommended Windows download.

## Changes

- Upgraded the Electron runtime from 37.10.3 to 43.4.0.
- Resolved the high-severity upstream advisories reported by `npm audit`.
- Revalidated the full glass calendar and compact island interfaces.
- Rebuilt and smoke-tested the Windows installer.

## Install

1. Download `HOVER-Setup-1.0.1.exe` below.
2. Run the installer and choose an installation folder.
3. Launch HOVER from the Desktop or Start menu shortcut.

HOVER is not code-signed, so Windows SmartScreen may show an **Unknown publisher** message. Verify that the installer came from this official release before selecting **More info -> Run anyway**. A SHA-256 checksum file is included with the release assets.

## Requirements

- Windows 10 or Windows 11, 64-bit.
