# HOVER 1.0.0

> **Superseded:** Install HOVER 1.0.1 or newer. Version 1.0.0 used an Electron runtime affected by newly reported upstream security advisories.

The first public Windows release of HOVER: a compact reminder calendar designed to stay visible without taking over the desktop.

## Highlights

- Transparent iOS-inspired glass interface with smooth panel and reminder-block animations.
- Sticky-note-sized full calendar plus a compact Dynamic Island-style mode.
- One-time and daily reminders with native Windows notifications.
- Press-and-hold dragging to move reminders along the timeline.
- Complete controls in both calendar and island modes.
- Back, Next, and Go to today navigation with the selected date shown correctly.
- Optional always-on-top behavior and an in-app Desktop shortcut action.
- Local-only reminder storage with no account, analytics, or cloud dependency.

## Install

1. Download `HOVER-Setup-1.0.0.exe` below.
2. Run the installer and choose an installation folder.
3. Launch HOVER from the Desktop or Start menu shortcut.

HOVER 1.0.0 is not code-signed, so Windows SmartScreen may show an **Unknown publisher** message. Verify that the installer came from this official release before selecting **More info → Run anyway**. A SHA-256 checksum file is included with the release assets.

## Requirements

- Windows 10 or Windows 11, 64-bit.
