# Using HOVER

## Create a reminder

Select the circular **+** button or press `Ctrl+N`. Add a title, date, start and end time, then choose whether HOVER should notify you at the start time or up to 30 minutes beforehand.

Reminders can run once or repeat every day. Five colors are available to keep different kinds of work visually distinct.

## Edit or move a reminder

- Select a calendar block to open its editor.
- Hold a block for a moment, then drag it vertically to reschedule it.
- Dragging snaps to 15-minute intervals and keeps the original duration.
- Press `Esc` to close the editor.

## Complete a reminder

Select the circle at the left of a reminder block. The block animates away and is marked complete for that date.

Daily reminders return the following day, so completing today's occurrence does not delete the repeating reminder.

## Island mode

Select **Island mode** at the bottom of the calendar. HOVER collapses into a small, movable pill that shows the next reminder without occupying much screen space.

- Select the completion circle to finish the displayed reminder.
- Select the arrow on the right to expand the full calendar.
- Drag the pill from its empty area to reposition it.

HOVER remembers the selected window mode between launches.

## Always on top

The **Stay on top** switch keeps HOVER visible above other windows. Turn it off when you want HOVER to behave like a regular desktop window.

## Alarms and notifications

HOVER checks upcoming reminders while it is running. When an alarm is due, Windows displays a native notification and HOVER plays a short tone.

Completed reminders do not trigger alarms. Keep HOVER running for scheduled alarms to fire.

## Pair a phone

On first launch, choose **iPhone** or **Android**. HOVER shows an expiring QR code and a six-character fallback.

1. Scan the QR with the phone Camera app or the HOVER in-app scanner.
2. Allow notifications if you want mobile alerts.
3. Choose a HOVER username and save the recovery code.
4. Wait for the Windows panel to confirm the connection.

Pairing creates separate phone and desktop tokens. HOVER then syncs reminders and completed history in the background. If the network is unavailable, the Windows planner remains usable and retries later.

## Data and privacy

HOVER does not require an account or internet connection for local use. Reminder data is saved locally in Electron's application-data directory for the current Windows user. Pairing is optional and starts cloud sync only after a username is chosen.

Uninstalling HOVER leaves reminder data in place by default, allowing it to be restored after reinstalling.
