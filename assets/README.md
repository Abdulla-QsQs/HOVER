# HOVER app icon

The current icon is stored here as `hover.ico`, with `hover.png` as its preview/source-ready version.

HOVER automatically uses it for the window and for new desktop shortcuts. Existing shortcuts can be recreated from the **Add to desktop** button.

To rebuild it from a replacement image:

```powershell
python scripts/build-icon.py C:\path\to\new-icon.png
```
